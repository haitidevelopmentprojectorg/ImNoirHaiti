IMNOIR — GitHub Pages upload package

FILES TO PUT IN THE ROOT OF YOUR NEW REPOSITORY:
- index.html
- styles.css
- script.js

GitHub Pages setup:
1. Create the new repository.
2. Upload all three files directly to the repository root (do not put them inside another folder).
3. Go to Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Save.

The site uses remote Wikimedia Commons image links so you do not need to manually upload image files for the first version.
If an external image filename changes or is unavailable, the page remains functional; you can replace that individual URL later without changing the site structure.

Before publishing widely, review image-license requirements for individual Wikimedia Commons files and add attribution where required.
